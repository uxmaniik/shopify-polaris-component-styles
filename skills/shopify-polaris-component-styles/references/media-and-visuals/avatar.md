## Use

Use the native `s-avatar` component before creating custom Shopify-admin-looking UI.

## Native Examples

```tsx
<s-avatar data-measure="target" src="https://cdn.shopify.com/shopifycloud/web/assets/v1/vite/client/en/assets/shopify_glyph-CP0sn9hU.svg" alt="Avatar">Avatar</s-avatar>
```

## Properties

| Property | Type | Default | Required | Notes |
| --- | --- | --- | --- | --- |
| `initials` | string | none listed | yes | The initials to display in the avatar when no image is provided or fails to load. Typically one or two characters representing a person's first and last name initials, such as "JD" for John Doe. |
| `src` | string | none listed | yes | The URL or path to the avatar image. When provided, the image takes priority over `initials`. If the image fails to load or loads slowly, `initials` will be rendered as a fallback. |
| `size` | "small" \| "small-200" \| "base" \| "large" \| "large-200" | 'base' | yes | The size of the avatar image. `small-200`: Extra small avatar, suitable for compact displays or lists with many items. `small`: Small avatar, good for secondary contexts or tight layouts. `base`: Default size that wor... |
| `alt` | string | none listed | yes | Alternative text that describes the avatar for accessibility. Provides a text description of the avatar for users with assistive technology and serves as a fallback when the avatar fails to load. A well-written descri... |

## Wrapper Guidance

- Reuse an existing shared wrapper if the app has one.
- Keep new wrappers thin and delegate visual behavior to `s-avatar`.
- Map product semantics to Polaris attributes in one place.
- Avoid hard-coded padding, radius, shadow, border, background, text, and hover values unless the measured table is being used for a custom composition.

## Avoid

- Do not imitate this component with ad hoc CSS when the native element is available.
- Do not duplicate this styling in feature files.
- Do not claim exact values that are not present in this reference or freshly measured.
